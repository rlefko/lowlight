The [public repository](https://github.com/rlefko/lowlight) is configured and administrative access was verified. The active [main-branch ruleset](https://github.com/rlefko/lowlight/rules/26254576) requires PRs, resolved review conversations, up-to-date CI Gate results from GitHub Actions, and CodeQL results with no errors/warnings or medium-or-higher security findings. It blocks deletion and force pushes and has no bypass actors. Active rules were read back from GitHub after configuration.

Required hosted CI and CodeQL results are tracked in each PR's checks. Keep new PRs unmerged until checks pass and the owner reviews the concrete result. Owner review is a manual handoff because the PR author cannot self-approve. No release exists yet.

Current controls scope: Focus, Relax, Commute, Workout, and Reflective apply their complete existing preset values atomically. Energy and Mood are primary controls; Auto/manual Tempo and Variation live in More Controls. Slider gestures preview locally and submit one committed snapshot. Desired settings persist independently of the rendered song, including before first Play. Structural changes preserve the current signal path and apply at a prepared musical handoff; failure exposes explicit retry without granting playback permission. See the [controls contract, migration, and validation evidence](validation-listening-controls.md).

The two-hour production-worker controls soak passed: 230,400,000 stereo frames, 92 selections, all 28 intended settings changes applied, and all 28 superseded revisions excluded from application. All five presets and both Custom Variation extremes at 92 BPM appeared, all ten Next requests produced later selections, and five preparation suspensions completed. Five Float32 WAV excerpts preserve the raw sample bytes and cover their intended observed transitions. Preparation waits were omitted from those logical audio streams; the soak recorded 741 zero pulls and one short pull. These results establish offline control coverage, not uninterrupted device playback or subjective sound acceptance. See the [measurements, exact recipe, and excerpt timestamps](validation-listening-controls.md).

Individual live Warmth, Space, and Texture controls remain deferred, along with the associated smoothing and effect-transition acceptance. Presets retain their complete tone settings for the newly planned song. Milestone 7 is not a claim that these deferred controls or physical-device gates are complete. The final integration passed 40 app tests, two UI flows, all 173 regular audio cases, preserved reference comparisons, and the required local gates. The unsigned Release app is 11,227,672 bytes, 372,296 bytes above an equivalent fresh PR48 build and within budget. Subjective transition listening and physical-device acceptance remain open in the controls validation record.

Release gates include sound parity, release-candidate native/device soaks, on-device offline first launch and locked-screen playback, interruption/route behavior, energy/memory/size evidence, accessibility and appearance checks, dependency/asset license inventory, distribution-route review, and an explicit release decision. No App Store submission is authorized by completing a milestone.
