The [public repository](https://github.com/rlefko/lowlight) is configured and administrative access was verified. The active [main-branch ruleset](https://github.com/rlefko/lowlight/rules/26254576) requires PRs, resolved review conversations, up-to-date CI Gate results from GitHub Actions, and CodeQL results with no errors/warnings or medium-or-higher security findings. It blocks deletion and force pushes and has no bypass actors. Active rules were read back from GitHub after configuration.

Required hosted CI and CodeQL results are tracked in each PR's checks. Keep new PRs unmerged until checks pass and the owner reviews the concrete result. Owner review is a manual handoff because the PR author cannot self-approve. No release exists yet.

[PR #5](https://github.com/rlefko/lowlight/pull/5) merged with all hosted checks passing. Its Intel CodeQL runner and extraction guard remain in place; PR #10 reduced the tool archive size without changing the fresh app trace.

Current scope: PRs #12–#17 and [PR #18](https://github.com/rlefko/lowlight/pull/18) are merged with hosted checks passed. [PR #19](https://github.com/rlefko/lowlight/pull/19) is merged and retains only prepared sample frames reachable by the score, allowing the complete accepted score to fit the existing PCM limit; see [storage validation and remaining full-song gates](validation-sample-storage.md) and [hosted checks](https://github.com/rlefko/lowlight/pull/19/checks). [PR #20](https://github.com/rlefko/lowlight/pull/20) is merged and adds a bounded body loudness meter; see [meter validation](validation-loudness.md) and [hosted checks](https://github.com/rlefko/lowlight/pull/20/checks). [PR #21](https://github.com/rlefko/lowlight/pull/21) is merged and applies one prepared fixed gain before song peak protection; see [gain validation](validation-gain.md) and [hosted checks](https://github.com/rlefko/lowlight/pull/21/checks). [PR #22](https://github.com/rlefko/lowlight/pull/22) is merged and preserves original reference-note durations; see [reference timing validation](validation-reference-timing.md) and [hosted checks](https://github.com/rlefko/lowlight/pull/22/checks). [PR #23](https://github.com/rlefko/lowlight/pull/23) is merged and adds validated finite song layouts and streaming body selection; see [body selection validation](validation-song-body.md) and [hosted checks](https://github.com/rlefko/lowlight/pull/23/checks). [PR #24](https://github.com/rlefko/lowlight/pull/24) is merged and adds explicit mixer song origins; see [origin validation](validation-origins.md) and [hosted checks](https://github.com/rlefko/lowlight/pull/24/checks). Complete rack orchestration, Swift preparation rounding, nonzero-origin reference placement, two-rack transport, and playback remain later work. No native playback engine exists yet.

Release gates include sound parity, two-hour native soaks, on-device offline first launch and locked-screen playback, interruption/route behavior, energy/memory/size evidence, accessibility and appearance checks, dependency/asset license inventory, distribution-route review, and an explicit release decision. No App Store submission is authorized by completing a milestone.
