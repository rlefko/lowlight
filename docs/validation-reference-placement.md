# Reference song placement

The original renderer places each note at its rounded song-local time, then places the complete song at a separately rounded session origin. Rounding an absolute note time directly can produce a different frame. `NoteEvent.importReference(_:placingAt:)` makes the original local placement explicit using a supplied integer frame origin.

The importer rounds local onsets at 32 kHz before adding the origin. Guitar and piano retain independently rounded hold and release lengths; bass retains its combined duration rounding. Percussion's unused gate endpoints are rounded on the local clock before translation. The existing `importReference(_:)` entry point continues to retain absolute onsets, and decoding stored version-1 events preserves their endpoints.

The caller supplies the placement frame explicitly; the importer does not infer it by subtracting floating-point event times. It still validates the source records' common absolute/local offset and chronological order. Invalid origins, out-of-range translated endpoints, and locally reversed onsets reject the import. No planning, random draws, sample preparation, or rendering occurs in this conversion.

It includes all 738 events of the second original Focus song, placed at frame 3,150,769; 161 onsets differ by one frame from absolute-time rounding. Fifteen probes cover rounding ties, relocation, percussion metadata, invalid bounds, and ordering. Seven observations execute the original placement functions. Expected frame values have zero tolerance, and CI verifies their source inventory and rederives them without rewriting them.

This diagnostic retains the original local fades, finite length, and body boundaries, and does not mix two songs.

This API places note events only. A complete reference song still needs a matching render layout, fades, air origin, and body boundaries. Native schedules continue to use their shared absolute clock. The opt-in [shared preparation pool](validation-shared-preparation.md) accepts complete explicit reference inputs. Ownership transfer, overlap transport, global peak protection, and playback remain separate work.
