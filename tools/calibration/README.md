# Tonal Warmth calibration

`warmth-v1.f32` contains one little-endian Float gain for each of 100 tonal keys and 101 Warmth settings. Guitar uses keys 0 through 79 for notes 50 through 69 and four takes. Piano uses keys 80 through 99 for the same notes and one stereo take. Width is 101, with the Warmth bin increasing from 0 to 100 in each row. The 40,400-byte table derives from the 42 CC0 source recordings listed in the two sound-bank manifests. The provenance file records their manifest hashes, numeric preparation sources, generator, and table digest.

Generate a candidate on the pinned macOS toolchain with `tools/calibration/generate .build/warmth-candidate.f32`. The tool decodes, transposes, and high-pass filters one key at a time. It evaluates the causal LP4 through frame 28,799 for every bin, then uses the production preparation arithmetic to calibrate frames 3,840 through 28,799. Piano attack shaping follows this calibration. Compare candidate bytes with `Packages/LowlightAudio/Sources/LowlightAudio/Resources/warmth-v1.f32` before updating the shipped data or its provenance.

`scripts/check-repository` checks the hashes, table shape, and instrument gain ranges. Run `.tools/reference/bin/python3 -B tools/calibration/verify.py --compare` to compare all entries against the pinned v9 renderer. The check captures v9's high-passed source for each key and measures the difference between applying each native gain and applying the independent v9 gain. It uses the accepted tonal maximum and RMS error limits. Fixed-control mixer tests compare complete output words against baked native PCM.

Each preparer verifies the two manifest hashes and every tonal file before admitting its first calibrated rack. The app keeps one shared immutable native table. It designs coefficients for the current platform and computes 32,000 Double piano attack factors during setup. Each tonal sample retains its key and one high-passed PCM prefix. During playback, each voice applies the two filter sections, calibrated gain, and piano shaping before its event envelope and pan.
